Methodology

The systematic approach followed to build and evaluate the food delivery time prediction model.

Data Collection

Gathered dataset with key features like distance, traffic, weather, preparation time, and courier experience.

Data Cleaning

Handled missing values using forward fill and mean techniques to ensure dataset consistency.

Feature Engineering

Converted categorical variables into numerical format using encoding techniques for model training.

Data Splitting

Divided dataset into training and testing sets (80/20) to evaluate model performance effectively.

Model Training

Applied regression algorithms like Linear Regression to learn patterns and predict delivery time.

Model Evaluation

Evaluated model accuracy using predictions and correlation analysis to ensure reliable results.
